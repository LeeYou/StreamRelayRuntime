# ADR-0003：仅将 ECS 思想作为组合模式保留

## 状态

Accepted

## 背景

参考系统使用围绕游戏概念构建的 ECS-like 架构，例如 `Player`、`World`、`Space`、移动和传送。StreamRelayRuntime 面向 WebSocket 转发和远程控制后台，其核心领域对象是连接、会话、设备、命令和转发通道。

## 决策

StreamRelayRuntime 只在有价值的地方保留 ECS 启发式组合思想。运行时模块可以通过组件组合能力，但核心系统不会把游戏式 ECS 模型暴露为中心抽象。

## 影响

- 运行时避免游戏领域污染。
- 组件思想仍可用于连接、会话、通道等能力组合。
- 当 ECS 不必要时，领域模块可以选择更简单的状态机或服务对象设计。
