# ADR-0001：使用 C++17 作为语言基线

## 状态

Accepted

## 背景

StreamRelayRuntime 目标是一个长期运行、高并发的现代 C++ 后台。项目需要 RAII、智能指针、类型安全枚举、结构化绑定、`std::optional`、`std::variant` 以及现代标准库能力，同时又要保持 Windows 和 Linux 上成熟编译器的广泛支持。

## 决策

使用 **C++17** 作为项目语言基线。

## 影响

- 开发者可以使用现代所有权管理和类型安全特性。
- 项目可以兼容 Windows 和 Linux 上成熟稳定的工具链。
- 核心接口中不直接使用 C++20 特性，除非经过封装或显式条件保护。
